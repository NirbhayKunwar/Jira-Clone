# 04 — Tech Stack & Dependencies

Analysis of all core libraries used in this project:

* **React 19**: Responsive virtual DOM reconciliation.
* **Vite 8**: Rapid assets bundling and hot module reloading.
* **Tailwind CSS v4**: CSS-first layout theme configuration.
* **Zustand**: Fast and minimal client state management store.
* **TanStack React Query**: Server state cache synchronize.
* **Prisma ORM**: Relational schema mappings and type-safe database queries.
* **Express.js**: Backend routes routing pipeline.
